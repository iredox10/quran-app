# Contributing to Quran Nur

First off, thank you for considering contributing to Quran Nur! It's people like you that make Quran Nur a great app for the global Muslim community.

## Where do I go from here?

If you've noticed a bug or have a feature request, make one! It's generally best if you get confirmation of your bug or approval for your feature request before starting to code.

## Fork & create a branch

If this is something you think you can fix, then fork Quran Nur and create a branch with a descriptive name.

A good branch name would be (where issue #325 is the ticket you're working on):

```bash
git checkout -b 325-add-dark-mode
```

## Local Development

1. Clone your fork.
2. Run `npm install` or `bun install`.
3. Set up your `.env` by copying `.env.example`.
4. Run `npm run dev` to start the development server.

## Code Style

- Use `camelCase` for variable and function names.
- Use `PascalCase` for React components.
- Use Tailwind CSS utility classes instead of writing custom CSS whenever possible.
- Ensure your code is formatted correctly.

## Implementing your feature or bug fix

- Write clean, readable code.
- Add comments where the logic is complex.
- Ensure your UI changes are fully responsive and look good on mobile.
- Make sure no console errors are thrown.

## Submitting a Pull Request

1. Push your branch to your fork.
2. Open a Pull Request against the `main` branch of the original Quran Nur repository.
3. Fill out the PR template completely.
4. Wait for a review! A maintainer will review your code, and either merge it or request changes.

Jazakallah Khair for your contribution!
